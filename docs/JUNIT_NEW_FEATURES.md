# JUnit: новые функции PROTEIN STORE

Проверки собраны в src/test/java/util/NewFeaturesTest.java (тема — вложенная группа ThemeStorage).
Это адаптированный вариант ранее подготовленного набора для пяти функций: история просмотров, темы, популярные товары, остатки, статусы заказов.

Запуск из корня проекта на настроенном JDK 21:

```powershell
.\gradlew.bat test --rerun-tasks
```

Отчёт: build/reports/tests/test/index.html.
Init-скрипт и отдельное применение патча не нужны: настройки JUnit и методы discountedPrice/stockLabel включены в этот коммит.

Тесты не отправляют HTTP-запросов и не меняют Supabase. user.home временно указывает на @TempDir и восстанавливается после проверки. JavaFX-окна не создаются; JavaFX требуется как зависимость проекта. Проверки private-методов выполняются в classpath через reflection. Параллельность отключена.

Не проверяются: реальные RPC/UPSERT/PATCH, RLS, триггеры и конкурентность БД, пагинация ответов сервера, распространение CSS на окна. Локальные запреты клиента не доказывают защиту сервера.

При подготовке отсутствовали Java/Javac/Gradle: компиляция и выполнение тестов не подтверждены. Результаты следует получить фактическим запуском; успешное прохождение не заявляется.
