# H-DEF-01: раздел истории не отображается

Пользователь сообщил об отсутствии блока после добавления функции. Локальная версия исходников и роль пользователя пока не подтверждены.

При анализе найдена уязвимость точки установки: HistoryFeature.install вызывался после FXMLLoader.load, но до создания Scene. Поле firstNameField находится внутри содержимого ScrollPane; ранний lookup может не найти его до создания skin. Метод в таком случае завершался без добавления блока. Это вероятная причина, а не воспроизведённый на компьютере разработчика результат.

Изменение: вызов перенесён в finishLayout, выполняемый через Platform.runLater после stage.show, applyCss и layout. Проверка stage.getScene предотвращает работу отложенного обработчика с уже сменившимся экраном. Встроенная проверка historySection предотвращает повторное добавление. Ограничение роли покупателя сохраняется.

Повторная проверка необходима: обновить рабочую ветку, выполнить clean run, войти покупателем и открыть профиль. Затем проверить запись, повторное открытие и очистку истории. Сборка и повторный запуск исправления пока не выполнены. main и схема БД не изменяются.
