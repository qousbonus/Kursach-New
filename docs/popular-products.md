# Популярные товары — рабочий раздел курсовой

Статус: серверная миграция add_popular_products_function применена; Java-код подготовлен, сборка и испытания не выполнены.

Популярность определяется суммой order_items.quantity в заказах orders со статусом delivered за всё время. Просмотры, рейтинг, отменённые и ещё не доставленные заказы не учитываются. Включаются товары с is_available=true, в том числе временно отсутствующие на складе. Порядок: sold_quantity DESC, product_id ASC. Виджет запрашивает до 6 товаров; функция ограничивает параметр диапазоном 1–12.

get_popular_products является STABLE SECURITY DEFINER с пустым search_path и явными схемами. Она выдаёт только перечисленные товарные поля и суммарные продажи, не возвращает покупателей, адреса и отдельные заказы. EXECUTE предоставлен anon и authenticated, общий PUBLIC отозван. Это публичный агрегат для каталога, а не предоставление клиенту привилегированного ключа. Проблема отключённого RLS старых таблиц этой функцией не устраняется.

PopularProductsFeature подключается после CSS и layout в SceneManager. Блок появляется перед сеткой каталога у покупателя и гостя; у менеджера и администратора скрыт. Блок показывает глобальные лидеры и не фильтруется поисковой строкой или выбранной категорией. Фотографии берутся из image_url; во время загрузки область нейтральная, надпись «Нет фото» появляется при отсутствии ссылки или ошибке. Для цены применяется BigDecimal. Перед открытием запрашивается актуальная карточка товара. Запросы виджета выполняются в отдельном daemon-потоке с ограниченной очередью, интерфейс обновляется через Platform.runLater, результаты покинутого экрана не отображаются.

Нулевой результат и ошибка запроса отображаются по-разному. Случайные товары при отсутствии продаж не подставляются. Есть кнопка обновления. SQL-файл отражает уже применённую миграцию: повторно выполнять его в этом проекте не нужно.

План проверки (не выполнен): два товара с разным количеством проданных единиц; разные статусы заказов; равные продажи; скрытый товар; товар без остатка; отсутствие доставленных продаж; вызов гостем; обе темы; открытие актуального товара; отсутствие дублирования блока при навигации; ошибка сети и повторная загрузка. Фактические результаты и скриншоты добавляются после проверки. main не изменяется.
