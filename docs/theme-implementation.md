# Оформление: материал для курсовой

Статус: кандидат реализации; сборка и запуск не выполнены.

Main подключает ThemeManager после SceneManager.init. Менеджер наблюдает за окнами, сценами и динамическими узлами. К корню добавляются theme-root и theme-light/theme-dark, к сцене подключается theme.css. Слабые коллекции не удерживают закрытые окна.

Блок выбора вставляется перед личными данными профиля по firstNameField и profile-section-card. При изменении структуры профиля этот код нужно адаптировать. Выбор хранится для пользователя ОС в .protein-store/appearance.properties, не синхронизируется через Supabase. Отсутствующий или некорректный файл означает LIGHT. Запись через временный файл предшествует применению; при ошибке остаётся старая тема.

Нейтральные inline-фоны и текст преобразуются в смысловые CSS-цвета. Это адаптер совместимости, не полный перенос исходных стилей в CSS. Геометрия и цветные акценты сохраняются. Контраст цветных inline-элементов и popup-окон требует визуального аудита.

План испытаний (все НЕ ВЫПОЛНЕНЫ): переключение в обе стороны; переходы между экранами; модальные формы и Alert; перезапуск; некорректный файл; запрет записи; popup-списки и динамические строки; отсутствие дублирования блока и CSS. Фактические результаты и скриншоты добавляются после запуска. Тест оформления заказа с ROLLBACK не выполнялся.
