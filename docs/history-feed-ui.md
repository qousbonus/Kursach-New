# H-UI-02: ленты просмотренных товаров

Предыдущий блок истории пользователь подтвердил как работающий. Новая доработка интерфейса ещё не собрана и не протестирована.

В профиле предусмотрена горизонтальная прокручиваемая лента восьми последних товаров. Карточка содержит существующую фотографию из products.image_url, название, актуальную цену с учётом скидки, время просмотра и кнопку открытия. Во время загрузки фото место остаётся нейтральным без надписи. «Нет фото» показывается только при пустой ссылке или ошибке загрузки. Пустая история имеет отдельное сообщение.

Кнопка «Посмотреть все просмотренные товары» открывает вертикальную ленту карточек с обновлением и очисткой всей собственной истории. Записи загружаются по 20, кнопка «Показать ещё» появляется только при наличии следующей страницы. Прежнее ограничение интерфейса 50 товарами снято. Сортировка — время просмотра DESC, затем product_id DESC; курсор содержит эту пару. Дополнительная запись в запросе определяет наличие следующей страницы. Повторяющиеся ID при подгрузке не добавляются. Изменения истории с другого устройства во время просмотра не образуют неизменяемый снимок; для актуального порядка используется «Обновить».

Схема Supabase и политики RLS не меняются. Пользовательский JWT, фоновые запросы и защита от отображения результатов другой сессии сохраняются. Цвета используют существующие тематические классы. При закрытии полного списка превью обновляется, если профиль остаётся активным.

План проверки (не выполнен): горизонтальная прокрутка; фото во время загрузки, после успеха и после ошибки; открытие товара из обеих лент; подгрузка более 50 записей; одинаковые времена просмотров; отсутствие дубликатов; очистка с обновлением превью; пустая история; обе темы; ошибки сети и истёкшая сессия. Данные двух аккаунтов и RLS проверяются отдельно. Необходимо также проверить читаемость длинных названий и разную ширину окна.
